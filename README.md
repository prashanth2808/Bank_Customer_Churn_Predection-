# Bank Customer Churn Prediction

## Overview
This project aims to predict bank customer churn using machine learning. Customer churn occurs when customers stop doing business with a company. Identifying potential churners early allows the bank to take proactive measures to retain them.

## Dataset
The project uses the `Bank Customer Churn Prediction.csv` dataset, which contains customer demographics, account information, and whether the customer has churned.

## Tools & Libraries Used
- **Python 3**
- **Pandas & NumPy**: For data manipulation and analysis.
- **Matplotlib**: For data visualization.
- **Scikit-learn**: For machine learning modeling, preprocessing (Pipeline, ColumnTransformer), and hyperparameter tuning (RandomizedSearchCV).
- **Jupyter Notebook**: For interactive development and analysis.

## Project Structure
- `Bank_Customer_Churn_Prediction.ipynb`: The main Jupyter Notebook containing data exploration, preprocessing, model training, and evaluation.
- `Bank Customer Churn Prediction.csv`: The dataset used for training and testing the models.

## How to Run
1. Ensure you have Python installed along with the required libraries (`pandas`, `numpy`, `matplotlib`, `scikit-learn`, `jupyter`).
2. Clone this repository.
3. Open a terminal in the project directory and run:
   ```bash
   jupyter notebook
   ```
4. Open the `Bank_Customer_Churn_Prediction.ipynb` notebook and run the cells sequentially to see the analysis and model results.
